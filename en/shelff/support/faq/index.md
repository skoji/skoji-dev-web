## FAQ

### OCR-embedded text disappears (fixed in version 1.5) {#ocr-text-problem}

This issue was fixed in version 1.5 by changing how PDFs are saved. From version 1.5 onward, writing annotations no longer corrupts embedded OCR text.

If the OCR text in a PDF was corrupted by an earlier version, please re-run OCR using the software that originally performed it (such as Adobe Acrobat).
